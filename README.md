# The Trend Loft

A static e-commerce demo site for pre-loved luxury fashion (clothes, bags, shoes), built with plain HTML, CSS, and JavaScript.

## Features
- Product browsing by category with sorting (price, A–Z)
- Cart with quantity controls, stored in `localStorage`
- Product review/rating page
- Seller dashboard and offers management
- Light/dark (night) mode toggle
- Responsive layout (mobile, tablet, desktop)

## Structure
- `index.html`, `category*.html` — home and category pages
- `cartpage.html`, `myorders.html`, `userpage.html` — account/cart flow
- `offerpage.html`, `sellerdashboardpage.html` — seller tools
- `product-evaluation.html` — reviews
- `css/style.css` — shared styles and theme variables
- `js/script.js` — cart, sorting, theme, and rating logic

## Run
Open `index.html` in a browser — no build step required.
